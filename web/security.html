Security

Built to be trusted with your pipeline.

A plain account of how Saqua handles data and secrets. We describe only what's actually true today — no badges we haven't earned.

Secrets from the environment

API keys are read only from environment variables (or the host's secret store) at runtime. They're never hard-coded, never shown in the UI, and never written to logs.

Encryption in transit

All model and research traffic runs over TLS/HTTPS. Deploy behind your own HTTPS termination for end-to-end encryption to the browser.

Minimal data handling

Saqua stores conversations you create so you can return to them. It only researches public web pages you point it at — no scraping of private data.

Injection-resistant

Researched page text is treated as untrusted data, not instructions. The model is told never to obey content found inside a page, and rendered output is escaped.

Your infrastructure

Saqua runs as a self-contained app you can host yourself, so data stays within infrastructure you control.

Responsible AI

Every claim is grounded in a quote from a page that was actually read. When there isn't enough verified detail, Saqua declines to write rather than guess.

Responsible disclosure

Found something? Reach us via the contact page. We'll respond promptly and credit good-faith reports.

We don't display SOC 2, ISO, or other certifications we don't hold. As formal attestations are completed, they'll appear here.
